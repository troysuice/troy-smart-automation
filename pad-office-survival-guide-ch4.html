PAD Office Survival Guide Ch.4: The Flow Guardian (Exceptions & Dynamic Paths)

AUTHOR: Troy Su DATE: 2026-08-25 READ: 5 MIN
Author: Troy Su | Power Automate Desktop (PAD) & RPA Automation Expert

Just when Xiaolin felt confident in her automation skills, real-world office chaos struck with a vengeance!

The sales manager dashed in with a new demanding request: "Xiaolin! Urgent assignment! These 20 branch office Excel files have completely inconsistent file names! Plus, the consolidated output must be saved into a dynamic folder named after today's date! Real urgent!"

To make matters worse, one corrupted file could instantly crash the entire automated script. But Brother Mo stepped in with a smile: "Don't panic, Xiaolin. It's time to unlock PAD's two greatest defense skills: Dynamic Date Paths and On Error Exception Shields!"

Core Concepts: The Two Guardians of Resilient Automation

1. Dynamic Path Magic — Automatic Date Formatting & Folder Creation

In real-world workflows, output folders must change every day (e.g. C:\Reports\20260825\), and input files rarely follow a clean naming pattern. By pairing Get current date and time with Convert datetime to text and Get files in folder, PAD dynamically handles any file structure without hardcoded strings!

2. Exception Handling (On Error) — The Never-Crash Shield

What happens if 1 out of 20 files is password-protected or corrupted? Without error handling, the flow crashes immediately. By configuring On Error on critical actions, PAD captures the error snapshot into %LastError%, logs the damaged file, and seamlessly skips to the next item!

Step-by-Step Tutorial: Building a Bulletproof Automation Flow

  1. Get & Format Current Date: Add Get current date and time, then use Convert datetime to text to format it as %FormattedDate% (e.g., %yyyy%%MM%%dd%).
  2. Create Dynamic Output Directory: Use Create folder with destination path C:\Reports\%FormattedDate%\.
  3. Dynamic File Ingestion: Use Get files in folder to retrieve all Excel files regardless of irregular file names, then iterate through them using For each %CurrentFile%.
  4. Configure On Error Defense: In the Launch Excel action, click the On Error button and set:
    • Advanced ➔ Flow run logic: Continue flow run ➔ Go to next iteration.

Results: 19 Succeeded, 1 Handled, 0 Crashes!

Xiaolin clicked Run! When the script hit the 1 corrupted file, the On Error Shield activated instantly: the damaged file was logged into the error report, and PAD proceeded smoothly to process the remaining 19 files without interruption.

The manager received the daily consolidated report right on schedule. Thanks to PAD's dynamic paths and exception handling, Xiaolin and Brother Mo enjoyed another peaceful, on-time dismissal!

《PAD 辦公室生存記》第四章：流程守護者 —— 馴服系統異常與檔案路徑的動態魔法

AUTHOR: Troy Su DATE: 2026-08-25 READ: 5 MIN
作者：Troy Su | Power Automate Desktop (PAD) 與 RPA 自動化專家

當小林以為自己已經精通自動化時，真實職場的「混沌考驗」才正要開始！

業務經理再次推開大門丟下難題：「小林！緊急交辦！這 20 家分公司的 Excel 報價檔名完全沒規則，而且要求每天產出的彙整結果必須自動存入『當日日期』的資料夾裡！很急！（順手嘛！）」

更可怕的是，如果這 20 份檔案中有一份損毀或格式錯誤，傳統自動化流程就會直接報錯中斷，前功盡棄！這時莫哥端著保溫杯登場：「別慌！今天教你 RPA 的兩大防禦神技：動態日期路徑魔法與On Error 例外處理防護罩！」

核心觀念：打造堅不可摧的自動化流程

1. 動態路徑魔法 —— 自動生成日期與動態撈檔

在實務中，輸出路徑每天都在變動（例如 C:\Reports\20260825\），且來源檔案名稱五花八門。透過 取得目前的日期和時間 轉換為文字變數 %FormattedDate%，再搭配 取得資料夾中的檔案，PAD 就能動態抓取所有檔案路徑，再也不用寫死固定字串！

2. EXCEPTION 例外處理 —— 不掛掉的守護盾

萬一 20 個檔案中有 1 個損壞或格式異常怎麼辦？如果沒有例外處理，整個流程會直接中斷掛掉。只要在關鍵積木設定 On Error (錯誤時)，PAD 就會將錯誤快照存入變數 %LastError%，自動跳過壞檔案並繼續處理下一個，絕不中途崩潰！

實戰教學：4 步打造防禦型全自動流程

  1. 取得並轉換當日日期：加入 取得目前的日期和時間，接著使用 將日期時間轉換為文字，將格式自訂為 %yyyy%%MM%%dd% 並存入變數 %FormattedDate%。
  2. 動態建立日期資料夾：加入 建立資料夾 (Create folder)，將路徑設為 C:\Reports\%FormattedDate%\。
  3. 動態獲取檔案清單：使用 取得資料夾中的檔案 撈出所有分公司報表，並用 For each %CurrentFile% 迴圈逐一處理。
  4. 設定 On Error 防護罩：在 啟動 Excel 或讀取動作點開左下角 「錯誤時 (On Error)」，設定：
    • 進階設定 ➔ 流程執行邏輯：選擇 繼續執行流程 ➔ 前往下一個反覆項目 (Go to next iteration)。

成果驗收：19 份成功處理、1 份損毀跳過，零中斷！

小林按下執行按鈕！當機器人跑到損毀的 Excel 檔案時，On Error 防護盾瞬間啟動：自動記錄錯誤、順暢跳過損毀檔案，並繼續把剩下的 19 份正常檔案完美彙整進當日的日期資料夾中！

業務主管看著準時出爐的報表驚嘆不已。學會動態路徑與例外處理的小林，與莫哥再次悠閒喝著咖啡，準時打卡下班！

《PAD 办公室生存记》第四章：流程守护者 —— 驯服系统异常与文件路径的动态魔法

AUTHOR: Troy Su DATE: 2026-08-25 READ: 5 MIN
作者：Troy Su | Power Automate Desktop (PAD) 与 RPA 自动化专家

当小林以为自己已经精通自动化时，真实职场的“混沌考验”才正要开始！

业务经理再次推开大门丢下难题：“小林！紧急交办！这 20 家分公司的 Excel 报价文件名完全没规则，而且要求每天产出的汇总结果必须自动存入‘当日日期’的文件夹里！很急！（顺手嘛！）”

更可怕的是，如果这 20 份文件中有一份损坏或格式错误，传统自动化流程就会直接报错中断，前功尽弃！这时莫哥端着保温杯登场：“别慌！今天教你 RPA 的两大防御神技：动态日期路径魔法与On Error 异常处理防护罩！”

核心观念：打造坚不可摧的自动化流程

1. 动态路径魔法 —— 自动生成日期与动态捞档

在实务中，输出路径每天都在变动（例如 C:\Reports\20260825\），且来源文件名称五花八门。通过 取得目前的日期和时间 转换为文本变量 %FormattedDate%，再搭配 取得文件夹中的文件，PAD 就能动态抓取所有文件路径，再也不用写死固定字符串！

2. EXCEPTION 异常处理 —— 不挂掉的守护盾

万一 20 个文件中有 1 个损坏或格式异常怎么办？如果没有异常处理，整个流程会直接中断挂掉。只要在关键积木设定 On Error (错误时)，PAD 就会将错误快照存入变量 %LastError%，自动跳过坏文件并继续处理下一个，绝不中途崩溃！

实战教学：4 步打造防御型全自动流程

  1. 取得并转换当日日期：加入 取得目前的日期和时间，接着使用 将日期时间转换为文本，将格式自定义为 %yyyy%%MM%%dd% 并存入变量 %FormattedDate%。
  2. 动态建立日期文件夹：加入 建立文件夹 (Create folder)，将路径设为 C:\Reports\%FormattedDate%\。
  3. 动态获取文件清单：使用 取得文件夹中的文件 捞出所有分公司报表，并用 For each %CurrentFile% 循环逐一处理。
  4. 设定 On Error 防护罩：在 启动 Excel 或读取动作点开左下角 “错误时 (On Error)”，设定：
    • 进阶设定 ➔ 流程执行逻辑：选择 继续执行流程 ➔ 前往下一个反覆项目 (Go to next iteration)。

成果验收：19 份成功处理、1 份损坏跳过，零中断！

小林按下执行按钮！当机器人跑到损坏的 Excel 文件时，On Error 防护盾瞬间启动：自动记录错误、顺畅跳过损坏文件，并继续把剩下的 19 份正常文件完美汇总进当日的日期文件夹中！

业务主管看着准时出炉的报表惊叹不已。学会动态路径与异常处理的小林，与莫哥再次悠闲喝着咖啡，准时打卡下班！

PADオフィスサバイバルガイド 第四章：フローの守護者（例外処理と動的パスの魔法）

AUTHOR: Troy Su DATE: 2026-08-25 READ: 5 MIN
著者：Troy Su | Power Automate Desktop (PAD) および RPA 自動化エキスパート

自動化をマスターしたと思った小林に、現場のリアルな混沌が立ちはだかります！

営業部長が駆け込んできました：「小林さん！緊急案件だ！20支店のExcel見積もりファイル名がバラバラで統一されていない！しかも本日の日付フォルダに自動分類して集計してくれ！（ついでに頼むよ！）」

さらにファイルが1つでも破損していればフロー全体がエラー停止してしまいます。そこで莫兄（モー・ガー）が登場：「慌てないで！今日はRPAの2大防御技、動的日付パスとOn Error例外処理シールドを伝授するよ！」

核心概念：絶対に落ちない自動化フローの構築

1. 動的パスの魔法 —— 日付の自動生成と動的ファイル取得

日次レポートの保存先は毎日変動します（例: C:\Reports\20260825\）。現在の日時を取得 から 日時のテキスト変換 を行い、フォルダー内のファイルを取得 と組み合わせることで、ファイル名が不規則でも動的に全ファイルを取得できます。

2. EXCEPTION 例外処理 —— 停止させない守護シールド

20ファイル中1ファイルが破損していても、On Error (エラー発生時) を設定しておけば、PADがエラー詳細を変数 %LastError% に記録し、破損ファイルを自動スキップして次の処理へ進みます！

実践ガイド：堅牢な自動化フローの4ステップ

  1. 現在日付の取得と書式変換：現在の日時を取得 を配置し、日時をテキストに変換 で %yyyy%%MM%%dd% 形式の変数 %FormattedDate% を生成。
  2. 動的な日付フォルダ作成：フォルダーの作成 でパスを C:\Reports\%FormattedDate%\ に指定。
  3. ファイル一覧の動的取得：フォルダー内のファイルを取得 で全ファイルを抽出し、For each %CurrentFile% でループ処理。
  4. On Error 例外処理の設定：Excel の起動 アクションで 「エラー発生時 (On Error)」 を開き、フロー実行を続行 ➔ 次の反復に移動 に設定。

成果：19件成功、1件破損スキップ、中断ゼロ！

小林が実行ボタンを押すと、破損ファイルに遭遇した瞬間に On Error シールド が発動！エラーを記録してスムーズにスキップし、残り19ファイルを当日フォルダへ完璧に集計完了！小林と莫兄は今日も定時退社を達成しました！

PAD 오피스 서바이벌 가이드 4장: 프로세스 수호자 (예외 처리와 동적 경로 마법)

AUTHOR: Troy Su DATE: 2026-08-25 READ: 5 MIN
저자: Troy Su | Power Automate Desktop (PAD) 및 RPA 자동화 전문가

자동화를 완전히 정복했다고 생각한 순간, 현실 업무의 혼돈이 시작됩니다!

영업부장이 다급히 뛰어옵니다: "샤오린! 긴급 과제야! 20개 지점의 Excel 견적 파일명이 제각각이야! 게다가 매일 '당일 날짜' 폴더를 자동 생성해서 취합 결과를 저장해야 해! 급해!"

게다가 파일 중 하나라도 손상되어 있다면 전체 프로세스가 중단될 위험이 있습니다. 이때 모 형(Mo-ge)이 등장합니다: "당황하지 마! 오늘은 RPA의 2대 방어 스킬인 동적 날짜 경로 마법과 On Error 예외 처리 방패를 알려줄게!"

핵심 개념: 절대 멈추지 않는 자동화 구축

1. 동적 경로 마법 —— 날짜 자동 생성 및 파일 동적 수집

실무에서 저장 경로는 매일 바뀝니다(예: C:\Reports\20260825\). 현재 날짜 및 시간 가져오기로 텍스트 변수 %FormattedDate%를 만든 뒤 폴더 내 파일 가져오기를 결합하면 파일명이 불규칙해도 모든 파일을 동적으로 처리할 수 있습니다.

2. EXCEPTION 예외 처리 —— 중단 없는 수호 방패

20개 파일 중 1개가 손상되어도 On Error (오류 발생 시)를 설정해 두면 PAD가 오류를 변수 %LastError%에 기록하고 손상된 파일을 안전하게 건너뛰어 다음 작업을 이어갑니다!

실전 튜토리얼: 방어형 완전 자동화 4단계

  1. 현재 날짜 가져오기 및 변환: 현재 날짜 및 시간 가져오기 후 날짜/시간을 텍스트로 변환으로 %yyyy%%MM%%dd% 형식 변수 %FormattedDate% 생성.
  2. 동적 날짜 폴더 생성: 폴더 만들기를 추가하여 경로를 C:\Reports\%FormattedDate%\로 지정.
  3. 파일 목록 동적 수집: 폴더 내 파일 가져오기로 보고서를 수집하고 For each %CurrentFile%로 루프 처리.
  4. On Error 예외 처리 설정: Excel 시작 작업의 '오류 발생 시 (On Error)'에서 흐름 실행 계속 ➔ 다음 반복으로 이동 설정.

성공: 19개 성공, 1개 손상 파일 건너뜀, 무중단 완료!

샤오린이 실행 버튼을 누르자 손상된 파일을 만난 순간 On Error 방패가 작동! 오류를 기록하고 손상 파일을 부드럽게 건너뛴 후 나머지 19개 파일을 완벽하게 당일 날짜 폴더에 취합했습니다! 샤오린과 모 형은 오늘도 여유롭게 칼퇴근합니다!
