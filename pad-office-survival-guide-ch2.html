PAD Office Survival Guide Ch.2: Taming the Data Beast (Variables & Excel Automation)

AUTHOR: Troy Su DATE: 2026-08-20 READ: 5 MIN
Author: Troy Su | Power Automate Desktop (PAD) & RPA Automation Expert

In Chapter 1, Xiaolin witnessed the amazing power of PAD PDF automation and was eager to try more. But workplace emergencies always arrive without warning!

Just when Xiaolin thought it was time to pack up and go home, the sales manager burst into the office pushing a cart overloaded with urgent files: "Xiaolin! Urgent assignment from the sales department! Consolidate the monthly sales reports from these 50 branch offices into one master Excel workbook before you leave! Real urgent!"

Staring at 50 Excel files, manual copying and pasting would take at least 150 minutes. Xiaolin was on the verge of breakdown. At this critical moment, Brother Mo stepped in with his warm tea: "Don't panic. Throw away Ctrl+C/V! Let our software robot handle this piece of cake."

Core Concepts: The Two Secret Weapons of Automation

Processing dozens or hundreds of files does not mean creating 50 repetitive steps manually. In Power Automate Desktop, you only need to master two core building blocks:

1. Variables — The "Magic Storage Box"

A variable is like a labeled container used to store folder paths, text, numbers, or entire data tables dynamically. In PAD, variables are wrapped in percent symbols, such as %FolderName% or %ExcelData%. Whenever you point actions to a variable name rather than hardcoding static text, your workflow becomes fully dynamic!

2. Loops (For Each) — The "Rubber Stamp Robot"

A loop instructs the robot to execute the exact same set of actions repeatedly across a list. Think of stamping 50 documents one by one: you only configure the steps (Open Excel ➔ Read Data ➔ Write Data ➔ Close) once, and the For Each loop automatically repeats them for all 50 branch files.

Step-by-Step Tutorial: Build Your Excel Consolidator in PAD

  1. Set Variable for Folder Path: In the Actions pane, add Set variable. Name it %FolderName% and set its value to your reports folder path (e.g. C:\Reports\).
  2. Launch Excel with Dynamic Path: Add Launch Excel. Instead of picking a fixed file name, use the variable %FolderName% so PAD can dynamically process every file.
  3. Read & Dynamic Append: Use Read from Excel worksheet into variable %ExcelData%. Then, in the master summary workbook, use Get first free column/row and Write to Excel worksheet to append each branch's data to the first blank row without overwriting previous entries!

Assembling the Flow: One-Click Execution with For Each

In the Actions pane, drag a For each loop onto the canvas and set the target list variable. Move your complete block—Launch Excel ➔ Read ➔ Find Blank Row ➔ Write ➔ Close Excel—directly inside the loop.

Xiaolin took a deep breath and clicked Run! Windows flashed rapidly on the screen as the robot effortlessly opened, extracted, appended, and saved all 50 files in just a few minutes!

Victory: Leaving Work on Time!

A popup flashed: "Execution Succeeded!" Opening the consolidated workbook, all 50 branches' sales figures lined up with 100% precision. What originally took 150 minutes of painful manual work was completed automatically in under 3 minutes.

《PAD 辦公室生存記》第二章：馴服資料巨獸（變數與 Excel 自動化）

AUTHOR: Troy Su DATE: 2026-08-20 READ: 5 MIN
作者：Troy Su | Power Automate Desktop (PAD) 與 RPA 自動化專家

在第一章中，小林親身體會了 PAD 處理 PDF 自動化的強大威力，正躍躍欲試想多學幾招。然而，職場上的危機總是來得猝不及防——

正當小林以為今天終於能準時收拾包袱下班時，辦公室大門被猛然推開！業務部經理推著整整一推車的「急件」檔案大喊：「小林！業務部緊急交辦，把這 50 個分公司的 Excel 銷售月報，下班前整理成一個彙整檔案。很急！（順手嘛！）」

看著眼前堆積如山的 50 份檔案，手動複製貼上少說要 150 分鐘，眼看黑色星期五又要淪陷為加班地獄……這時，莫哥再次端著保溫杯現身救援：「別哭了，把 Ctrl+C / Ctrl+V 丟掉吧。這點小事，讓機器人幫你做好啦！」

核心觀念：自動化的兩大關鍵法寶

想要一次性批次處理幾十個、甚至上百個檔案，根本不需要重複寫 50 次一模一樣的動作。在 RPA 的世界裡，只要掌握兩個核心概念：

1. 變數（Variable）—— 數據的「魔法收納盒」

變數就像一個貼了標籤的收納盒，用來隨時存放資料夾路徑、文字、數字或整張資料表。在 PAD 中，變數會用前後百分比符號包起來，例如 %FolderName% 或 %ExcelData%。只要把積木參數指向變數名稱，就能讓流程動態讀取不同資料，不再被寫死的數值綁架！

2. 迴圈（For Each Loop）—— 蓋印章機器人

迴圈就是讓機器人重複執行同一套動作。就像拿著同一顆印章依序在 50 份文件上蓋章一樣：我們只需要把「開啟 Excel ➔ 讀取數據 ➔ 寫入總表 ➔ 關閉檔案」的標準動作設定好一次，放進 For Each 迴圈中，機器人就會自動把 50 份檔案依序處理完畢。

實戰教學：4 步打造 Excel 自動彙整機器人

  1. 設定變數存放資料夾路徑：在動作清單找到 設定變數 (Set variable)，變數名稱設為 %FolderName%，值指向存放 50 份月報的資料夾（如 C:\Reports\）。
  2. 動態啟動 Excel：加入 啟動 Excel (Launch Excel)，路徑設定使用變數 %FolderName%，不需要寫死固定檔案名稱。
  3. 讀取與動態寫入空白列：使用 從 Excel 工作表讀取 存入變數 %ExcelData%；在彙整總表中使用 取得 Excel 工作表中第一個空閒的欄/列 找到最新空行，再透過 寫入 Excel 工作表 依序寫入，確保資料絕不互相覆蓋！

組合魔法：套入 For Each 迴圈一鍵執行

在動作清單找到 迴圈 (For each) 拖入流程，設定重複處理對象為檔案清單變數。將剛才設定好的 啟動 Excel ➔ 讀取資料 ➔ 尋找空白列 ➔ 寫入資料 ➔ 關閉 Excel 動作積木全部拖入迴圈內部。

小林深吸一口氣，按下綠色的 「執行 (Run)」 按鈕！螢幕視窗飛速自動切換，機器人不知疲倦地在幾分鐘內自動讀取、合併並儲存了所有報表！

成果驗收：準時下班的奇蹟！

螢幕跳出 「執行成功」 的對話框！打開彙整完成的 Excel 總表，50 家分公司的數據整整齊齊排好隊，數千筆資料分毫不差！原本需要苦幹 150 分鐘的複製貼上，機器人 3 分鐘零失誤搞定！

下一章精彩預告：如果分公司的銷售數據不在本機資料夾，而是分散在每天都需要帳號密碼登入的內部 ERP 系統或廠商後台呢？第三章我們將正式制服「網頁迷宮」，學習 PAD 網頁自動登入與抓取！敬請期待！

《PAD 办公室生存记》第二章：驯服数据巨兽（变量与 Excel 自动化）

AUTHOR: Troy Su DATE: 2026-08-20 READ: 5 MIN
作者：Troy Su | Power Automate Desktop (PAD) 与 RPA 自动化专家

在第一章中，小林亲身体会了 PAD 处理 PDF 自动化的强大威力，正跃跃欲试想多学几招。然而，职场上的危机总是来得猝不及防——

正当小林以为今天终于能准时收拾包袱下班时，办公室大门被猛然推开！业务部经理推着整整一推车的“急件”档案大喊：“小林！业务部紧急交办，把这 50 个分公司的 Excel 销售月报，下班前整理成一个汇总档案。很急！（顺手嘛！）”

看着眼前堆积如山的 50 份档案，手动复制粘贴少说要 150 分钟，眼看黑色星期五又要沦陷为加班地狱……这时，莫哥再次端着保温杯现身救援：“别哭了，把 Ctrl+C / Ctrl+V 丢掉吧。这点小事，让机器人帮你做好啦！”

核心观念：自动化的两大关键法宝

想要一次性批量处理几十个、甚至上百个文件，根本不需要重复写 50 次一模一样的动作。在 RPA 的世界里，只要掌握两个核心概念：

1. 变量（Variable）—— 数据的“魔法收纳盒”

变量就像一个贴了标签的收纳盒，用来随时存放文件夹路径、文本、数字或整张数据表。在 PAD 中，变量会用前后百分比符号包起来，例如 %FolderName% 或 %ExcelData%。只要把积木参数指向变量名称，就能让流程动态读取不同数据，不再被写死的数值绑架！

2. 循环（For Each Loop）—— 盖印章机器人

循环就是让机器人重复执行同一套动作。就像拿着同一颗印章依次在 50 份文件上盖章一样：我们只需要把“打开 Excel ➔ 读取数据 ➔ 写入总表 ➔ 关闭文件”的标准动作设定好一次，放进 For Each 循环中，机器人就会自动把 50 份文件依次处理完毕。

实战教学：4 步打造 Excel 自动汇总机器人

  1. 设定变量存放文件夹路径：在动作清单找到 设定变量 (Set variable)，变量名称设为 %FolderName%，值指向存放 50 份月报的文件夹（如 C:\Reports\）。
  2. 动态启动 Excel：加入 启动 Excel (Launch Excel)，路径设定使用变量 %FolderName%，不需要写死固定文件名称。
  3. 读取与动态写入空白行：使用 从 Excel 工作表读取 存入变量 %ExcelData%；在汇总总表中使用 取得 Excel 工作表中第一个空闲的列/行 找到最新空行，再通过 写入 Excel 工作表 依次写入，确保数据绝不互相覆盖！

组合魔法：套入 For Each 循环一键执行

在动作清单找到 循环 (For each) 拖入流程，设定重复处理对象为文件清单变量。将刚才设定好的 启动 Excel ➔ 读取数据 ➔ 寻找空白行 ➔ 写入数据 ➔ 关闭 Excel 动作积木全部拖入循环内部。

小林深吸一口气，按下绿色的 “执行 (Run)” 按钮！屏幕窗口飞速自动切换，机器人在几分钟内自动读取、合并并保存了所有报表！

成果验收：准时下班的奇迹！

屏幕跳出 “执行成功” 的对话框！打开汇总完成的 Excel 总表，50 家分公司的数据整整齐齐排好队，数千条数据分毫不差！原本需要苦干 150 分钟的复制粘贴，机器人 3 分钟零失误搞定！

下一章精彩预告：如果分公司的销售数据不在本机文件夹，而是分散在每天都需要账号密码登录的内部 ERP 系统或厂商后台呢？第三章我们将正式制服“网页迷宫”，学习 PAD 网页自动登录与抓取！敬请期待！

PADオフィスサバイバルガイド 第二章：データの怪物を手懐ける（変数とExcel自動化）

AUTHOR: Troy Su DATE: 2026-08-20 READ: 5 MIN
著者：Troy Su | Power Automate Desktop (PAD) および RPA 自動化エキスパート

第1章でPADによるPDF自動化の威力を体感した小林は、さらなる挑戦に意欲を燃やしていました。しかし、職場のピンチは常に突然訪れます——

定時で帰ろうとしたその時、営業部長がワゴンいっぱいの至急書類を押して飛び込んできました：「小林さん！営業部からの至急案件だ。この50支店のExcel売上月報を退社までに1つのファイルにまとめてくれ！（ついでに頼むよ！）」

山積みの50ファイルを前に、手動コピー＆ペーストなら最低でも150分……絶望する小林の元に、莫兄（モー・ガー）が温かいお茶を持って現れました：「泣かないで、Ctrl+CとCtrl+Vは捨てちゃいな。こんなのロボットにやらせれば一瞬だよ！」

核心概念：自動化を支える2大魔法

何十、何百ものファイルを処理するために、50回同じ手順を書く必要はありません。RPAでは次の2つの概念さえ押さえれば完璧です：

1. 変数（Variable）—— データの「魔法の収納ボックス」

変数は、フォルダパスやテキスト、数値、データ表を保管しておくラベル付きの箱です。PADでは %FolderName% や %ExcelData% のようにパーセント記号で囲みます。固定値ではなく変数名を指定することで、動的に柔軟な処理が可能になります。

2. ループ（For Each）—— スタンプ押しロボット

ループとは、ロボットに同じ動作を繰り返し実行させる仕組みです。50通の書類に順番にスタンプを押すように、「Excel起動 ➔ データ読取 ➔ 集計表書込 ➔ 閉じる」という一連の動作を1度設定して For Each に入れるだけで、全ファイルを自動処理します。

実践ガイド：Excel自動集計フローの構築

  1. フォルダパスを変数に設定：アクションから 変数の設定 を配置し、変数名 %FolderName% にレポート格納先パス（例: C:\Reports\）を設定します。
  2. 動的にExcelを起動：Excel の起動 アクションで、ファイル名を直接固定せず変数 %FolderName% を指定します。
  3. データの読取と空白行への追記：Excel ワークシートからの読み取り でデータを %ExcelData% に格納。集計先では Excel ワークシートの最初の空の列/行を取得 を使って空行を特定し、Excel ワークシートへの書き込み でデータを追記します。

フローの結合：For Eachループでワンクリック実行

For each ループを配置し、ファイル一覧変数を対象に設定します。先ほど作成した「Excel起動 ➔ 読取 ➔ 空白行取得 ➔ 書込 ➔ 閉じる」のブロックをループ内にドラッグします。

小林が深呼吸して 「実行 (Run)」 ボタンを押すと、画面が自動で切り替わり、ロボットが瞬く間に50ファイルの集計を完了させました！

成果と次回予告：定時退社の奇跡！

画面に「実行成功」のダイアログが表示されました。完成した集計表を開くと、50支店の全データが完璧に並んでいます。手作業で150分かかっていた作業が、わずか3分でノーミス完了です！

PAD 오피스 서바이벌 가이드 2장: 데이터 몬스터 길들이기 (변수와 Excel 자동화)

AUTHOR: Troy Su DATE: 2026-08-20 READ: 5 MIN
저자: Troy Su | Power Automate Desktop (PAD) 및 RPA 자동화 전문가

1장에서 PAD의 PDF 자동화 위력을 체험한 샤오린은 자신감이 붙었습니다. 하지만 직장의 위기는 늘 예고 없이 찾아옵니다——

정시 퇴근을 준비하던 순간, 영업부장이 서류 카트를 밀고 들어와 외칩니다: "샤오린! 긴급 업무야. 50개 지점의 Excel 매출 월보를 퇴근 전까지 하나의 종합 파일로 정리해 줘! 급해!"

산더미 같은 50개 파일을 수동으로 복사·붙여넣기 하려면 최소 150분…… 절망에 빠진 샤오린에게 모 형(Mo-ge)이 다가옵니다: "울지 마, Ctrl+C / Ctrl+V는 버려! 이런 일은 소프트웨어 로봇에게 맡기면 돼."

핵심 개념: 자동화의 2대 필살기

수십, 수백 개의 파일을 처리하기 위해 똑같은 작업을 50번 반복할 필요가 없습니다. RPA에서는 다음 두 가지만 알면 충분합니다:

1. 변수 (Variable) —— 데이터의 "마법 수납함"

변수는 폴더 경로, 텍스트, 숫자, 표 데이터를 담아두는 이름표 달린 상자입니다. PAD에서는 %FolderName%, %ExcelData%와 같이 퍼센트 기호로 감쌉니다. 고정된 값을 쓰지 않고 변수명을 지정하면 프로세스가 데이터를 동적으로 처리합니다.

2. 루프 (For Each Loop) —— 도장 찍기 로봇

루프는 로봇이 동일한 동작을 반복 수행하도록 합니다. 50장의 서류에 차례대로 도장을 찍듯이, 'Excel 실행 ➔ 데이터 읽기 ➔ 종합표 쓰기 ➔ 닫기' 단계를 한 번만 구성하여 For Each에 넣으면 로봇이 50개 파일을 자동으로 순회합니다.

실전 튜토리얼: Excel 자동 취합 로봇 만들기

  1. 폴더 경로 변수 설정: 작업 목록에서 변수 설정을 추가하고, 변수명 %FolderName%에 보고서 폴더 경로(예: C:\Reports\)를 지정합니다.
  2. 동적 Excel 실행: Excel 시작 작업에서 고정 파일명 대신 변수 %FolderName%을 사용합니다.
  3. 데이터 읽기 및 빈 행 동적 쓰기: Excel 워크시트에서 읽기로 데이터를 %ExcelData%에 저장한 후, 종합 파일에서 Excel 워크시트의 첫 번째 빈 열/행 가져오기로 빈 줄을 찾아 Excel 워크시트에 쓰기로 순서대로 입력합니다.

흐름 결합: For Each 루프로 원클릭 실행

For each 루프를 배치하고 파일 목록 변수를 지정한 뒤, Excel 실행 ➔ 읽기 ➔ 빈 행 찾기 ➔ 쓰기 ➔ 닫기 블록 전체를 루프 안으로 넣습니다.

샤오린이 심호흡 후 실행 (Run) 버튼을 누르자 화면이 빠르게 전환되며 로봇이 단 몇 분 만에 50개 파일을 완벽하게 취합했습니다!

성공과 다음 장 예고: 정시 퇴근의 기적!

화면에 "실행 성공" 알림이 떴습니다! 종합 문서를 열어보니 50개 지점의 데이터가 오차 없이 깔끔하게 정리되어 있었습니다. 150분 걸릴 작업을 단 3분 만에 무결점으로 끝냈습니다!
