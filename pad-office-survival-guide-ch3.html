PAD Office Survival Guide Ch.3: Web Scraping & Automated Email Operation

AUTHOR: Troy Su DATE: 2026-08-23 READ: 5 MIN
Author: Troy Su | Power Automate Desktop (PAD) & RPA Automation Expert

Just after mastering Excel automation in Chapter 2, a new workplace crisis strikes! At 1:00 PM, the sales manager bursts in with another sudden task: "Xiaolin! Urgent assignment from sales: scrape the latest price lists from all 30 supplier websites and compile them into a master report before 2:00 PM! Real urgent!"

30 websites, manual browsing, copying and pasting would take at least 180 minutes! Xiaolin is once again on the verge of despair. But Brother Mo steps in with a smile: "Don't panic, Xiaolin. Let our software robots handle this small task. That's the real power of PAD!"

Core Concepts: The Two Secret Weapons of Web & Email Automation

Instead of manually opening browser tabs one by one, PAD provides two specialized action groups that work seamlessly together:

1. Web Elf (Browser Automation) — The Invisible Data Harvester

Like an invisible assistant, PAD can automatically launch Chrome or Edge, navigate through 30 supplier URLs, accurately scrape target price tables, and store all structured data directly into variable %SupplierPrices% (or %ExtractedData%) without touching your mouse!

2. Auto Postman (Outlook Actions) — Headless Email Dispatcher

No need to open the Outlook app and type manually! PAD connects directly to the email backend. It takes the freshly extracted price table, pairs it with dynamically generated subject lines %MailSubject%, and dispatches the alert email straight to your manager.

Step-by-Step Tutorial: Building the End-to-End Automation Flow

  1. Launch Browser Instance: Use Launch new Chrome / Edge. This creates a browser instance variable %Browser%, allowing all subsequent actions to control the web page precisely.
  2. Extract Data from Web Page: Add Extract data from web page. Select the target price table visually, and rename the output variable to %SupplierPrices% for clean readability.
  3. If Condition Gatekeeper: Add an If [ Price > Threshold ] logic block.
    • If True (Price too high): Set %MailSubject% to [High Price Alert! Item: %CurrentProduct%, Price: %CurrentPrice%].
    • Else (Normal price): Set %MailSubject% to [Normal Price: Item: %CurrentProduct%].

Assembling the Flow: Automated Dispatch & Resource Cleanup

After checking prices with the If condition, add Send email message through Outlook:

  • To: Manager's Email
  • Subject: %MailSubject%
  • Body: %ExtractedData% (HTML table or summary)

Finally, add Close web browser to release system resources. Wrap everything inside a For each loop across all 30 supplier URLs, and click Run!

Victory: 100% Accuracy and On-Time Dismissal!

In less than 5 minutes, 30 supplier websites were scraped and all alert emails were dispatched seamlessly! The manager checked the report and praised Xiaolin's amazing efficiency. Xiaolin and Brother Mo walked out of the office on time with coffee in hand.

《PAD 辦公室生存記》第三章：網頁資料抓取與自動郵寄大作戰

AUTHOR: Troy Su DATE: 2026-08-23 READ: 5 MIN
作者：Troy Su | Power Automate Desktop (PAD) 與 RPA 自動化專家

剛在第二章學會 Excel 自動彙整的小林，信心大增！然而下午一點，辦公室大門又被猛然推開——業務經理帶著新的急件殺到：「小林！業務部又臨時交辦，把這 30 家供應商官網的最新報價抓下來！下午兩點前整理成一個表格檔案。很急！（順手嘛！）」

30 家供應商網站、手動開網頁複製貼上至少要 180 分鐘！眼看兩點死線就要到了，莫哥再次端著保溫杯帥氣登場：「別慌，小林。這點小事，讓機器人幫你做好啦。這就是 PAD 的威力！」

核心觀念：PAD 網頁與郵件自動化的兩大魔法

要搞定跨網頁資料擷取與即時通報，不需要手忙腳亂開幾十個瀏覽器分頁。在 PAD 中，我們有兩大核心幫手：

1. 網頁小精靈（網頁動作群）—— 隱形資料收割機

它就像隱形助手，能自動開啟 Chrome 或 Edge 瀏覽器、精準定位並擷取 30 家供應商網頁上的價格表格，不用動手點滑鼠，就能把資料整整齊齊收進變數 %SupplierPrices%（或 %ExtractedData%）中！

2. 自動郵差（Outlook 動作群）—— 背景發信專家

不需要打開 Outlook 軟體介面手動打字！它能直接讀取剛剛抓到的報價資料，配上根據規則動態產生的高價警示主旨 %MailSubject%，直接在背景寄給主管！

實戰教學：3 步打造「網頁抓取 + 條件發信」全自動流

  1. 建立並控制瀏覽器實例：加入 啟動新 Chrome / Edge 動作，產生瀏覽器實例變數 %Browser%，這是所有網頁自動化的基石。
  2. 從網頁擷取表格資料：使用 從網頁擷取資料 (Extract data from web page)，選定供應商官網的報價表格，將資料存入變數並命名為 %SupplierPrices%。
  3. 條件判斷 If 門衛積木：加入 If [ 價格 > 閾值 ] 邏輯：
    • 若價格過高：設定變數 %MailSubject% 為 [價格過高警示！商品: %CurrentProduct%, 價格: %CurrentPrice%]。
    • 若價格正常 (Else)：設定變數 %MailSubject% 為 [正常價格: 商品: %CurrentProduct%]。

流程串接與自動發信

在判斷完價格與動態主旨後，加入 透過 Outlook 傳送電子郵件訊息：

  • 收件者 (To)：主管信箱
  • 主旨 (Subject)：%MailSubject%（動態主旨）
  • 內文 (Body)：%ExtractedData%（抓取到的表格資料）

最後加上 關閉網頁瀏覽器 釋放電腦資源。將這套標準動作放進 For each 迴圈遍歷 30 家供應商網址，按下 執行 (Run)！

成果驗收：準時下班的奇蹟再現！

不到 5 分鐘，30 家供應商的最新報價全部自動抓取完畢，高價警示信也一封不漏地寄送到主管信箱！主管看著即時又準確的報表連聲稱讚，小林與莫哥準時下班喝咖啡，完美結束充實的一天！

核心观念：PAD 网页与邮件自动化的两大魔法

要搞定跨网页数据提取与实时通报，不需要手忙脚乱开几十个浏览器标签页。在 PAD 中，我们有两大核心帮手：

实战教学：3 步打造“网页抓取 + 条件发信”全自动流

    • 若价格正常 (Else)：设定变量 %MailSubject% 为 [正常价格: 商品: %CurrentProduct%]。

流程串接与自动发信

PADオフィスサバイバルガイド 第三章：Webスクレイピングと自動メール大作戦

AUTHOR: Troy Su DATE: 2026-08-23 READ: 5 MIN
著者：Troy Su | Power Automate Desktop (PAD) および RPA 自動化エキスパート

第2章でExcel自動集計をマスターした小林。しかし午後1時、営業部長が新たな緊急案件を持って現れました：「小林さん！サプライヤー30社の最新見積もりを各社サイトから取得して、14時までに一覧にしてくれ！急ぎで！（ついでに頼むよ！）」

30サイトを手動で巡回してコピペすれば最低180分……締め切りまで1時間しかない絶望的な状況に、莫兄（モー・ガー）が再び登場：「慌てないで小林さん。これくらいロボットに任せれば一瞬だよ。それがPADの威力さ！」

核心概念：Webとメール自動化の2大魔法

何十ものブラウザタブを手動で開く必要はありません。PADの2大アクション群を組み合わせます：

1. Webの妖精（ブラウザ自動化）—— 見えないデータ収集機

ChromeやEdgeを自動起動し、30社のWebサイトを巡回して価格表を正確にスクレイピング。マウス操作なしで、抽出データを変数 %SupplierPrices% に格納します。

2. 自動郵便配達人（Outlookアクション）—— バックグラウンド送信

Outlookアプリを開いて手入力する必要はありません！抽出したデータを読み込み、条件に応じた件名 %MailSubject% を動的に設定して、自動で上司宛てにメールを送信します。

実践ガイド：Webデータ抽出と条件分岐メールフロー

  1. ブラウザインスタンスの制御：新しい Chrome / Edge を起動 を配置し、インスタンス変数 %Browser% を生成します。
  2. Webページからデータを抽出：Web ページからデータを抽出する で価格表を選択し、変数 %SupplierPrices% に保存します。
  3. If条件分岐：If [ 価格 > 閾値 ] ブロックを追加：
    • 高額な場合：件名変数 %MailSubject% を [価格高騰警告！商品: %CurrentProduct%, 価格: %CurrentPrice%] に設定。
    • 通常価格の場合 (Else)：[通常価格: 商品: %CurrentProduct%] に設定。

フローの結合と自動送信

Outlook を介してメール メッセージを送信 を追加し、宛先、動的件名 %MailSubject%、本文 %ExtractedData% を設定。Web ブラウザーを閉じる でメモリを解放し、For each ループで30社分を自動実行します！

成果：わずか5分で完了、定時退社！

全30社の見積もりがミスなく取得され、高額警告メールも完璧に送信されました。上司からの高評価を受け、小林と莫兄は今日も定時退社を達成しました！

PAD 오피스 서바이벌 가이드 3장: 웹 스크래핑과 자동 이메일 대작전

AUTHOR: Troy Su DATE: 2026-08-23 READ: 5 MIN
저자: Troy Su | Power Automate Desktop (PAD) 및 RPA 자동화 전문가

2장에서 Excel 자동 취합을 마스터한 샤오린! 하지만 오후 1시, 영업부장이 새 긴급 과제를 들고 뛰어옵니다: "샤오린! 30개 공급사 웹사이트의 최신 단가를 스크래핑해서 오후 2시 전까지 표로 정리해 줘! 진짜 급해!"

30개 사이트를 수동으로 열어 복사·붙여넣기 하면 최소 180분…… 마감까지 1시간 남은 절망의 순간, 모 형(Mo-ge)이 다시 등장합니다: "당황하지 마, 샤오린. 이런 작은 일은 로봇에게 맡기면 돼. 이게 바로 PAD의 힘이야!"

핵심 개념: 웹 및 이메일 자동화의 2대 필살기

수십 개의 브라우저 탭을 열 필요 없이, PAD의 두 가지 핵심 작업 그룹을 사용합니다:

1. 웹 요정 (브라우저 자동화) —— 보이지 않는 데이터 수집기

Chrome이나 Edge를 자동 실행하여 30개 공급사 웹페이지를 순회하고, 단가 표를 정확하게 스크래핑하여 변수 %SupplierPrices%에 깔끔하게 저장합니다.

2. 자동 우체부 (Outlook 작업) —— 백그라운드 발송 전문가

Outlook 앱을 열고 일일이 작성할 필요가 없습니다! 추출된 데이터를 불러와 조건에 따른 동적 제목 %MailSubject%과 함께 상사에게 이메일을 자동 발송합니다.

실전 튜토리얼: 웹 스크래핑 + 조건부 이메일 발송 흐름 구축

  1. 브라우저 인스턴스 시작: 새 Chrome / Edge 시작을 추가하고 브라우저 제어 변수 %Browser%를 생성합니다.
  2. 웹페이지에서 데이터 추출: 웹 페이지에서 데이터 추출을 사용하여 가격표를 선택하고 변수 %SupplierPrices%에 저장합니다.
  3. If 조건문 문지기: If [ 가격 > 임계값 ] 블록을 추가:
    • 고가인 경우: 제목 변수 %MailSubject%를 [가격 과다 경고! 상품: %CurrentProduct%, 가격: %CurrentPrice%]로 설정.
    • 정상 가격인 경우 (Else): [정상 가격: 상품: %CurrentProduct%]로 설정.

흐름 결합 및 자동 발송

Outlook을 통해 이메일 메시지 보내기를 추가하여 받는 사람, 동적 제목 %MailSubject%, 본문 %ExtractedData%를 설정하고, 웹 브라우저 닫기로 리소스를 정리합니다. For each 루프로 30개사를 묶어 실행 (Run)!

성공: 5분 만에 완료, 정시 퇴근 달성!

30개 사의 단가가 완벽하게 추출되고 고가 경고 메일까지 완벽히 발송되었습니다! 부장의 극찬을 받으며 샤오린과 모 형은 오늘도 여유롭게 정시 퇴근합니다!
