PAD Office Survival Guide Ch.5: Smart Assistant (Human-in-the-Loop & Dynamic Filters)

AUTHOR: Troy Su DATE: 2026-08-26 READ: 5 MIN
Author: Troy Su | Power Automate Desktop (PAD) & RPA Automation Expert

In the real office, business rules change every single day! Just as Xiaolin sat down, the manager dropped another twist: "Xiaolin! Filter these 30 supplier price sheets by different months and custom price thresholds, then generate separate reports for different departments! Very urgent!"

Xiaolin gasped: "If the criteria change every time, do I have to modify the script parameters manually every day? What if I make a typo?!"

Brother Mo smiled: "RPA is not here to replace you—it's here to take your orders! Today, let's build a Human-in-the-Loop Smart Assistant using Custom Forms and Multi-Condition Branching!"

Core Concepts: Human-in-the-Loop & Multi-Condition Decisions

1. Smart Input Dialogs — Custom Forms (Display Custom Form)

Instead of hardcoding rules into your workflow or editing actions daily, create an interactive GUI dialog. When the flow starts, a pop-up collects parameters such as Month, Price Threshold, and Target Department into variable %CustomFormData% dynamically.

2. Multi-Branch Decision Tree — Advanced If / Else If

Feed user inputs into multi-branch logic:

  • If (Month == %MonthInput% && Price > %ThresholdInput%) ➔ High-Price Alert for Management
  • Else If (Month == 'November' && Department != 'Sales') ➔ Standard Department Summary
  • Else ➔ Routine Archiving

Step-by-Step Tutorial: Building the Interactive Assistant

  1. Design Custom Form: Add Display custom form to create input fields for Month, Price Threshold, and a dropdown for Department. Output values are stored in %CustomFormData%.
  2. Pass Parameters into Loop: In the For each %CurrentFile% loop, use the dynamic inputs from the form to filter rows in each supplier workbook.
  3. Branch Logic with If / Else If: Route each filtered result to specific email templates and department recipients based on the form selections.
  4. Integrate Exception Shield: Keep the On Error protection enabled on Excel actions so damaged files are safely bypassed without interrupting the run.

Results: Maximum Flexibility, Zero Code Edits, On-Time Dismissal!

Xiaolin just filled in the prompt dialog ("October", "1500 USD", "Sales"), clicked Submit, and watched PAD process all 30 files, filter out high-price items, handle corrupted files seamlessly, and email the reports to respective departments!

The manager was amazed by the instantaneous turnaround. Xiaolin and Brother Mo picked up their boba tea and walked out of the office on time with a huge smile!

《PAD 辦公室生存記》第五章：智慧助手登場 —— 馴服動態篩選與人機互動魔法

AUTHOR: Troy Su DATE: 2026-08-26 READ: 5 MIN
作者：Troy Su | Power Automate Desktop (PAD) 與 RPA 自動化專家

在真實職場中，商業邏輯與主管的需求總是天天在變！小林剛坐下，業務經理又丟來新任務：「小林！這 30 家供應商的報價單，這次要篩選出特定月份、特定價格門檻的商品，並將結果產生新的 Excel 報表寄給不同部門！很急！（順手嘛！）」

小林倒抽一口氣：「每次篩選條件和寄送部門都不一樣，難道我每天都要進流程後台手動修改 If 積木參數嗎？萬一改錯一個字不就全毀了？！」

莫哥笑著端著茶走過來：「別慌！RPA 不是要取代你，而是聽你指揮！今天就來打造人機協作魔法介面，結合自訂表單與多重條件決策，讓流程隨時依你的指令靈活應變！」

核心觀念：人機協作（Human-in-the-Loop）與進階多重條件

1. 智慧輸入對話盒 —— 自訂表單（Display Custom Form）

與其每次手動改流程程式碼，不如在流程啟動時彈出一個直覺的 UI 輸入視窗！透過「顯示自訂表單」動作，讓使用者自由填入「月份」、「價格門檻」並從下拉選單挑選「寄送部門」，所有參數自動收進變數 %CustomFormData%！

2. 多重決策樹 —— If / Else If 進階門衛

將表單取得的動態變數帶入多重邏輯判斷：

  • If (月份 == %MonthInput% && 價格 > %ThresholdInput%) ➔ 觸發高價警示並寄送主管
  • Else If (月份 == '11月' && 部門 != '業務部') ➔ 產出一般月報寄送對應部門
  • Else ➔ 執行一般日常歸檔

實戰教學：4 步打造人機協作智慧助理

  1. 建立自訂表單對話盒：加入 顯示自訂表單 (Display custom form) 動作，設計「月份輸入框」、「價格門檻輸入框」與「部門下拉選單」，將輸入值存入 %CustomFormData%。
  2. 動態套入檔案迴圈：在 For each %CurrentFile% 迴圈中，利用表單輸入的變數動態比對 30 家供應商報價單中的資料行。
  3. 設定 If / Else If 多重門衛：依據篩選結果與指定部門，動態組裝 Excel 彙整表與寄送郵件主旨。
  4. 搭配 On Error 例外防護：延續前一章的例外處理機制，即使遇到損毀檔案也能自動記錄並跳過，流程整體穩定不中斷！

成果驗收：靈活應變零改動，準時喝珍奶下班！

小林在彈出的對話盒中填入「10月」、「1500元」、「業務部」並按下確定，PAD 隨即自動依指示過濾 30 份報價、精準抽出符合項目、生成專屬報表並發送給業務部！遇到 1 份損毀檔案也自動跳過，全程零失誤！

業務主管驚嘆小林的驚人應變效率。完全掌握「人機協作」與「例外防護」的小林，與莫哥拿著珍奶，再次開心準時下班！

小林倒抽一口气：“每次筛选条件和寄送部门都不一样，难道我每天都要进流程后台手动修改 If 积木参数吗？万一改错一个字不就全毁了？！”

莫哥笑着端着茶走过来：“别慌！RPA 不是要取代你，而是听你指挥！今天就来打造人机协作魔法界面，结合自定义表单与多重条件决策，让流程随时依你的指令灵活应变！”

核心观念：人机协作（Human-in-the-Loop）与进阶多重条件

1. 智慧输入对话框 —— 自定义表单（Display Custom Form）

与其每次手动改流程代码，不如在流程启动时弹出一个直观的 UI 输入窗口！通过“显示自定义表单”动作，让使用者自由填入“月份”、“价格门槛”并从下拉菜单挑选“寄送部门”，所有参数自动收进变量 %CustomFormData%！

2. 多重决策树 —— If / Else If 进阶门卫

将表单取得的动态变量带入多重逻辑判断：

  • If (月份 == %MonthInput% && 价格 > %ThresholdInput%) ➔ 触发高价警示并寄送主管
  • Else If (月份 == '11月' && 部门 != '业务部') ➔ 产出一般月报寄送对应部门
  • Else ➔ 执行一般日常归档

实战教学：4 步打造人机协作智慧助理

  1. 建立自定义表单对话框：加入 显示自定义表单 (Display custom form) 动作，设计“月份输入框”、“价格门槛输入框”与“部门下拉菜单”，将输入值存入 %CustomFormData%。

  4. 搭配 On Error 异常防护：延续前一章的异常处理机制，即使遇到损坏文件也能自动记录并跳过，流程整体稳定不中断！

PADオフィスサバイバルガイド 第五章：スマートアシスタント登場（動的フィルタと人機協調の魔法）

AUTHOR: Troy Su DATE: 2026-08-26 READ: 5 MIN
著者：Troy Su | Power Automate Desktop (PAD) および RPA 自動化エキスパート

実際のビジネス現場では、業務ルールや指示は日々変わります！営業部長がまた新たな課題を持ってきました：「小林さん！30社の見積もりから、月別・指定金額以上の商品を抽出して各部署へ個別送付してくれ！急ぎで！」

小林は叫びます：「条件が変わるたびにフローを開いてIfアクションを手動修正するなんて、ミスが怖くてやってられません！」

莫兄（モー・ガー）がアドバイス：「RPAは人間の指示に従う相棒だ！今日はカスタムフォームを活用した人機協調スマートアシスタントを作ろう！」

核心概念：人機協調（Human-in-the-Loop）と多重条件分岐

1. スマート入力ダイアログ —— カスタムフォーム（Display Custom Form）

毎回コードを書き換える代わりに、実行時にパラメータ（対象月・価格閾値・送信先部署）を入力するUIダイアログを表示し、変数 %CustomFormData% に格納します。

2. 多重条件分岐 —— If / Else If の高度な制御

フォームの動的入力を条件分岐に渡します：

  • If (対象月 == %MonthInput% && 価格 > %ThresholdInput%) ➔ 高額アラートメール送付
  • Else If (対象月 == '11月' && 部署 != '営業部') ➔ 通常月報を他部署へ送付
  • Else ➔ 通常アーカイブ処理

実践ガイド：人機協調フローの4ステップ

  1. カスタムフォームの作成：カスタム フォームを表示 アクションで月、金額、部署の入力欄を設計。
  2. ループ内での動的照合：For each %CurrentFile% 内で、フォーム入力値を用いて各ファイルを動的フィルタリング。
  3. If / Else If による送信先分岐：条件に応じてExcelファイルを生成し、対応部署へ自動メール送信。
  4. On Error 例外処理の併用：破損ファイルがあっても自動スキップして処理を継続。

成果：柔軟な対応力でミスゼロ、定時退社！

ダイアログに必要な条件を入力するだけで、PADが自動で30社をフィルタリングして個別送信を完了！破損ファイルも自動処理され、小林と莫兄は今日もタピオカミルクティーを手に定時退社しました！

PAD 오피스 서바이벌 가이드 5장: 스마트 비서 등장 (동적 필터링과 인간-로봇 협업)

AUTHOR: Troy Su DATE: 2026-08-26 READ: 5 MIN
저자: Troy Su | Power Automate Desktop (PAD) 및 RPA 자동화 전문가

실제 업무 현장에서는 요구사항이 매일 바뀝니다! 영업부장이 또 긴급 업무를 던집니다: "샤오린! 30개 공급사 단가표에서 특정 월, 특정 금액 이상의 상품을 필터링해 각 부서로 각각 발송해 줘! 급해!"

샤오린이 당황합니다: "조건이 매번 바뀌는데, 매일 플로우 백엔드에 들어가 If 블록 파라미터를 수정해야 하나요? 오타라도 나면 어떡하죠?!"

모 형(Mo-ge)이 웃으며 말합니다: "RPA는 너의 지시를 따르는 조력자야! 사용자 정의 폼을 활용한 인간-로봇 협업 스마트 비서를 만들어 보자!"

핵심 개념: 인간-로봇 협업(Human-in-the-Loop)과 다중 조건 분기

1. 스마트 입력 대화상자 —— 사용자 정의 폼 (Display Custom Form)

매번 코드를 수정하는 대신, 실행 시 파라미터(대상 월, 금액 기준, 발송 부서)를 묻는 UI 대화창을 띄워 변수 %CustomFormData%에 즉시 저장합니다.

2. 다중 조건 분기 —— If / Else If 고급 제어

대화상자에서 받은 동적 변수를 다중 조건문에 전달합니다:

  • If (월 == %MonthInput% && 금액 > %ThresholdInput%) ➔ 고가 경고 메일 발송
  • Else If (월 == '11월' && 부서 != '영업부') ➔ 해당 부서로 월보 발송
  • Else ➔ 일반 보관 처리

실전 튜토리얼: 인간-로봇 협업 4단계

  1. 사용자 정의 폼 생성: 사용자 지정 양식 표시로 월, 금액, 부서 입력창을 디자인.
  2. 루프 내 동적 필터링: For each %CurrentFile% 루프 안에서 폼 입력값으로 30개사 데이터를 동적 비교.
  3. If / Else If 조건 분기: 조건에 따라 Excel 보고서를 생성하고 해당 부서로 자동 이메일 전송.
  4. On Error 예외 처리 결합: 손상된 파일이 있어도 건너뛰고 안정적으로 전체 실행 유지.

성공: 코드 수정 없이 완벽 처리, 정시 퇴근!

대화상자에 조건만 입력하면 PAD가 알아서 30개 파일을 필터링하고 부서별 발송까지 완벽히 마칩니다! 샤오린과 모 형은 오늘도 버블티를 들고 기분 좋게 정시 퇴근합니다!
