如何尋找 PAD 工作流程 ID 以供 Orchestrator 部署

AUTHOR: Troy Su DATE: 2026-08-06 READ: 3 MIN
作者：Troy Su | Power Automate Desktop (PAD) 與 RPA 自動化專家

在使用 PAD Orchestrator 或其他外部工具來觸發 Power Automate Desktop 腳本時，最關鍵的步驟就是取得該腳本專屬的「工作流程 ID (Workflow ID)」。這組 ID 是 PAD 系統辨識腳本的唯一憑證。

這串 ID 通常是一長串包含英數字與連字號的 GUID (例如：12345678-abcd-1234-abcd-1234567890ab)。以下將教你兩種最快找出這串 ID 的方法。

方法一：透過建立桌面捷徑尋找 (最推薦)

這是最簡單且不容易複製錯誤的方法：

  1. 打開你的 Power Automate Desktop 應用程式主畫面（控制台）。
  2. 在清單中找到你想要排程執行的工作流程。
  3. 點擊該工作流程右側的 三個點 (更多動作) 圖示。
  4. 在選單中選擇 建立桌面捷徑 (Create desktop shortcut)。
  5. 回到你的 Windows 桌面，找到剛剛建立的捷徑，對著它點擊 右鍵 > 內容 (Properties)。
  6. 在「捷徑」頁籤中，找到 目標 (Target) 欄位。你會看到類似下方這樣的一串指令：
"C:\Program Files (x86)\Power Automate Desktop\PAD.Console.Host.exe" -run -workflowId 12345678-abcd-1234-abcd-1234567890ab

其中，在 -workflowId 後面的那串代碼 12345678-abcd-1234-abcd-1234567890ab 就是你的 PAD ID！將這串 ID 複製起來，貼到 PAD Orchestrator 的設定檔中即可完成綁定。

方法二：透過工作流程屬性尋找

如果你不想在桌面建立捷徑，也可以直接在軟體內查看：

  1. 同樣在 Power Automate Desktop 主畫面找到你的工作流程。
  2. 點擊右側的三個點 (更多動作)。
  3. 選擇 屬性 (Properties) 或 詳細資料 (Details)。
  1. 在彈出的視窗中，切換到「詳細資料」，找到 流程識別碼 (Flow ID) 欄位，直接點擊旁邊的複製按鈕即可。

注意：新版本的 PAD 介面可能會稍微調整屬性視窗的排版，如果找不到，請直接使用「方法一」最為保險。

部署至 PAD Orchestrator

取得這串 ID 後，將它填入 PAD Orchestrator 的腳本設定欄位中。Orchestrator 就能在指定的時間，或是指定的觸發條件下，精準地呼叫這串 ID，啟動真正的無人值守自動化流程！

如何查找 PAD 工作流 ID 以供 Orchestrator 部署

AUTHOR: Troy Su DATE: 2026-08-06 READ: 3 MIN

当我们准备通过 PAD Orchestrator 或其他外部排程工具（例如 Windows 任务计划程序、命令行 CMD）来触发 Power Automate Desktop 的脚本时，我们不能只提供脚本的“名称”，而是必须提供该脚本专属的 工作流 ID (Workflow ID)。

这串 ID 通常是一长串包含英数字与连字符的 GUID (例如：12345678-abcd-1234-abcd-1234567890ab)。以下将教你两种最快找出这串 ID 的方法。

方法一：通过创建桌面快捷方式查找 (最推荐)

这是最简单且不容易复制错误的方法：

  1. 打开你的 Power Automate Desktop 应用程序主画面（控制台）。
  2. 在列表中找到你想要排程执行的工作流。
  3. 点击该工作流右侧的 三个点 (更多操作) 图标。
  4. 在菜单中选择 创建桌面快捷方式 (Create desktop shortcut)。
  5. 回到你的 Windows 桌面，找到刚刚创建的快捷方式，对着它点击 右键 > 属性 (Properties)。
  6. 在“快捷方式”选项卡中，找到 目标 (Target) 字段。你会看到类似下方这样的一串指令：
"C:\Program Files (x86)\Power Automate Desktop\PAD.Console.Host.exe" -run -workflowId 12345678-abcd-1234-abcd-1234567890ab

其中，在 -workflowId 后面的那串代码 12345678-abcd-1234-abcd-1234567890ab 就是你的 PAD ID！将这串 ID 复制起来，贴到 PAD Orchestrator 的配置文件中即可完成绑定。

方法二：通过工作流属性查找

如果你不想在桌面创建快捷方式，也可以直接在软件内查看：

  1. 同样在 Power Automate Desktop 主画面找到你的工作流。
  2. 点击右侧的三个点 (更多操作)。
  3. 选择 属性 (Properties) 或 详细信息 (Details)。
  1. 在弹出的窗口中，切换到“详细信息”，找到 流程识别码 (Flow ID) 字段，直接点击旁边的复制按钮即可。

注意：新版本的 PAD 界面可能会稍微调整属性窗口的排版，如果找不到，请直接使用“方法一”最为保险。

部署至 PAD Orchestrator

取得这串 ID 后，将它填入 PAD Orchestrator 的脚本设定字段中。Orchestrator 就能在指定的时间，或是指定的触发条件下，精准地调用这串 ID，启动真正的无人值守自动化流程！

How to Find Your PAD Workflow ID for Orchestrator Deployment

AUTHOR: Troy Su DATE: 2026-08-06 READ: 3 MIN

When preparing to trigger a Power Automate Desktop script via PAD Orchestrator or other external scheduling tools (such as Windows Task Scheduler or CMD), providing the script's "name" is not enough. You must provide the script's unique Workflow ID.

This ID is typically a long GUID containing alphanumeric characters and hyphens (e.g., 12345678-abcd-1234-abcd-1234567890ab). Here are the two fastest ways to find this ID.

Method 1: Create a Desktop Shortcut (Recommended)

This is the simplest method and minimizes copy-paste errors:

  1. Open your Power Automate Desktop main console.
  2. Locate the workflow you want to schedule from the list.
  3. Click the three dots (More actions) icon on the right side of the workflow.
  4. Select Create desktop shortcut from the menu.
  5. Go to your Windows desktop, find the newly created shortcut, and right-click > Properties.
  6. In the "Shortcut" tab, find the Target field. You will see a command similar to this:
"C:\Program Files (x86)\Power Automate Desktop\PAD.Console.Host.exe" -run -workflowId 12345678-abcd-1234-abcd-1234567890ab

The code immediately following -workflowId (in this case, 12345678-abcd-1234-abcd-1234567890ab) is your PAD ID! Copy this ID and paste it into your PAD Orchestrator configuration to complete the binding.

Method 2: Check Workflow Properties

If you prefer not to create a desktop shortcut, you can find it within the app:

  1. Locate your workflow on the Power Automate Desktop console.
  2. Click the three dots (More actions) on the right.
  3. Select Properties or Details.
  1. In the pop-up window, switch to the "Details" tab and find the Flow ID field. Simply click the copy button next to it.

Note: Newer versions of PAD might slightly alter the layout of the properties window. If you cannot find it, using Method 1 is the most foolproof approach.

Deploying to PAD Orchestrator

Once you have obtained this ID, enter it into the script configuration field of PAD Orchestrator. The Orchestrator will then be able to accurately call this ID at specified times or under specific trigger conditions, initiating true unattended automation!

Orchestrator展開のためのPADワークフローIDの見つけ方

AUTHOR: Troy Su DATE: 2026-08-06 READ: 3 MIN

PAD Orchestratorやその他の外部スケジューリングツール（WindowsタスクスケジューラやCMDなど）を使用してPower Automate Desktopスクリプトをトリガーする場合、スクリプトの「名前」を提供するだけでは不十分です。スクリプト固有のワークフローID（Workflow ID）を提供する必要があります。

このIDは通常、英数字とハイフンを含む長いGUIDです（例：12345678-abcd-1234-abcd-1234567890ab）。このIDを見つけるための最も早い2つの方法を紹介します。

方法1：デスクトップショートカットを作成する（推奨）

これは最も簡単な方法であり、コピーのミスを防ぎます。

  1. Power Automate Desktopのメインコンソールを開きます。
  2. リストからスケジュールしたいワークフローを見つけます。
  3. ワークフローの右側にある3つの点（その他のアクション）アイコンをクリックします。
  4. メニューからデスクトップショートカットの作成（Create desktop shortcut）を選択します。
  5. Windowsのデスクトップに移動し、新しく作成されたショートカットを見つけて、右クリック > プロパティ（Properties）を選択します。
  6. 「ショートカット」タブで、リンク先（Target）フィールドを見つけます。以下のようなコマンドが表示されます。
"C:\Program Files (x86)\Power Automate Desktop\PAD.Console.Host.exe" -run -workflowId 12345678-abcd-1234-abcd-1234567890ab

-workflowIdの直後にあるコード（この例では12345678-abcd-1234-abcd-1234567890ab）があなたのPAD IDです！このIDをコピーして、PAD Orchestratorの構成に貼り付ければ完了です。

方法2：ワークフローのプロパティを確認する

デスクトップにショートカットを作成したくない場合は、アプリ内で確認することもできます。

  1. Power Automate Desktopコンソールでワークフローを見つけます。
  2. 右側の3つの点（その他のアクション）をクリックします。
  3. プロパティ（Properties）または 詳細（Details）を選択します。
  1. ポップアップウィンドウで、「詳細」タブに切り替え、フローID（Flow ID）フィールドを見つけます。その横にあるコピーボタンをクリックするだけです。

注：新しいバージョンのPADでは、プロパティウィンドウのレイアウトがわずかに変更されている場合があります。見つからない場合は、方法1を使用するのが最も確実です。

PAD Orchestratorへの展開

このIDを取得したら、PAD Orchestratorのスクリプト構成フィールドに入力します。これにより、Orchestratorは指定された時間または特定のトリガー条件でこのIDを正確に呼び出し、真の無人自動化を開始できるようになります！

Orchestrator 배포를 위한 PAD 워크플로우 ID 찾는 방법

AUTHOR: Troy Su DATE: 2026-08-06 READ: 3 MIN

PAD Orchestrator 또는 기타 외부 스케줄링 도구(예: Windows 작업 스케줄러 또는 CMD)를 통해 Power Automate Desktop 스크립트를 트리거할 준비를 할 때 스크립트의 "이름"을 제공하는 것만으로는 충분하지 않습니다. 스크립트의 고유한 워크플로우 ID(Workflow ID)를 제공해야 합니다.

이 ID는 일반적으로 영숫자 문자와 하이픈이 포함된 긴 GUID입니다(예: 12345678-abcd-1234-abcd-1234567890ab). 이 ID를 찾는 가장 빠른 두 가지 방법은 다음과 같습니다.

방법 1: 바탕 화면 바로 가기 만들기 (권장)

이것은 가장 간단한 방법이며 복사 오류를 최소화합니다.

  1. Power Automate Desktop 기본 콘솔을 엽니다.
  2. 목록에서 예약할 워크플로우를 찾습니다.
  3. 워크플로우 오른쪽에 있는 점 3개(추가 작업) 아이콘을 클릭합니다.
  4. 메뉴에서 바탕 화면 바로 가기 만들기(Create desktop shortcut)를 선택합니다.
  5. Windows 바탕 화면으로 이동하여 새로 만든 바로 가기를 찾은 다음 마우스 오른쪽 버튼 클릭 > 속성(Properties)을 선택합니다.
  6. "바로 가기" 탭에서 대상(Target) 필드를 찾습니다. 다음과 유사한 명령이 표시됩니다.
"C:\Program Files (x86)\Power Automate Desktop\PAD.Console.Host.exe" -run -workflowId 12345678-abcd-1234-abcd-1234567890ab

-workflowId 바로 뒤에 오는 코드(이 경우 12345678-abcd-1234-abcd-1234567890ab)가 PAD ID입니다! 이 ID를 복사하여 PAD Orchestrator 구성에 붙여넣어 바인딩을 완료합니다.

방법 2: 워크플로우 속성 확인

바탕 화면에 바로 가기를 만들고 싶지 않은 경우 앱 내에서 찾을 수도 있습니다.

  1. Power Automate Desktop 콘솔에서 워크플로우를 찾습니다.
  2. 오른쪽에 있는 점 3개(추가 작업)를 클릭합니다.
  3. 속성(Properties) 또는 세부 정보(Details)를 선택합니다.
  1. 팝업 창에서 "세부 정보" 탭으로 전환하고 흐름 ID (Flow ID) 필드를 찾습니다. 옆에 있는 복사 버튼을 클릭하기만 하면 됩니다.

참고: 최신 버전의 PAD에서는 속성 창의 레이아웃이 약간 변경되었을 수 있습니다. 찾을 수 없는 경우 방법 1을 사용하는 것이 가장 확실한 방법입니다.

PAD Orchestrator에 배포

이 ID를 얻었으면 PAD Orchestrator의 스크립트 구성 필드에 입력합니다. 그러면 Orchestrator가 지정된 시간이나 특정 트리거 조건에서 이 ID를 정확하게 호출하여 진정한 무인 자동화를 시작할 수 있습니다!
